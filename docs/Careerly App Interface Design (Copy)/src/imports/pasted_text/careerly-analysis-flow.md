# Careerly — 职业分析启动流程补全

请基于当前 Careerly App 已有的视觉设计，
补全「分析」模块在进入“正在分析你的职业状态”之前缺失的所有交互页面。

当前已有页面存在明显流程断点：

用户点击“分析”后，
目前直接进入：

“正在分析你的职业状态”

但用户实际上还没有提供：

1. 简历
2. 目标岗位 JD

因此必须补齐完整的职业分析启动流程。

--------------------------------------------------
三、整体设计原则
--------------------------------------------------

所有新增页面必须严格继承 Careerly 当前视觉语言。

参考当前已有页面：

- 浅蓝 → 白 → 浅粉渐变背景
- 蓝紫渐变品牌色
- 白色半透明玻璃卡片
- 大圆角
- 柔和阴影
- Material 3
- Android 手机界面
- 精致
- 克制
- 温暖
- 专业
- AI 产品感

不要重新定义视觉系统。

不要引入新的设计语言。

不要做成传统招聘网站。

不要做成复杂表单。

核心目标：

让用户用最少步骤完成一次职业分析。

--------------------------------------------------
二十、分析入口页面不要做成表单
--------------------------------------------------

这是职业分析流程。

不是：

“填写资料”。

体验应该更像：

Careerly 在陪你完成一次职业诊断。

因此文案应该温暖、自然。

例如：

“先看看你的职业经历。”

“你想去哪里？”

“准备好了。”

而不是：

“请输入简历。”

“请输入岗位描述。”
