--------------------------------------------------
二、核心产品定位
--------------------------------------------------

Careerly 的产品核心：

“看见能力 · 跨越 Gap · 记录成长”

Careerly 不是普通个人中心。

“我的”也不是：

头像 + 设置 + 账号信息。

“我的”的核心定位应该是：

# 职业成长档案

它需要回答四个问题：

1. 我是谁？
2. 我积累了什么？
3. 我现在具备什么能力？
4. 我是怎么一步一步成长到现在的？

因此，“我的”页面必须同时包含：

当前职业状态
+
职业资产
+
能力
+
成长历程
+
简历
+
会员权益
