四十一、最重要的产品原则

请在整个 Figma Make 修改过程中始终遵守以下原则：

01

分析不是岗位推荐。

Careerly 不提供自己的岗位资源池。

02

分析不是一次性结果。

历史分析可以被再次更新。

03

更新分析不是覆盖。

旧结果保留，新结果建立新的结果记录。

04

分析页面不负责简历管理。

简历属于“我的 → 职业资产”。

05

分析页面不负责复杂版本管理。

前台只展示当前结果以及必要的“上次 → 本次”变化。

06

AI 结果必须尽可能有依据。

不要凭空生成用户没有提供的经历、技能或成果。

07

分析结果最终必须导向行动。

分析结果底部一定要有：

AI 改进点 → 下一步行动 → 进入 AI

最终设计目标

请不要把这个模块设计成一个“AI 分析工具页面集合”。

应该把它设计成一个非常清晰的产品闭环：

选择简历 → 添加多个目标岗位 → 看见匹配 → 理解 Gap → 获得行动建议 → 简历发生变化 → 更新分析 → 看见排名和匹配变化。

用户最终应该形成一个非常简单的认知：

“我想知道自己离目标岗位还有多远，就来分析。”

以及：

“我的简历变好了以后，我可以回来重新分析，看看自己的职业位置有没有发生变化。”
